Morse Decipher

Pourpose:
The objective of this program is to convert files containing Morse code into English text. 
The converted text will be saved in a new file, and the program will include valid error checking to ensure accurate processing.

Short individual reflection:
In the laboratory, I embarked on the development of a sophisticated program designed to convert Morse code from a user-selected file into readable English text. 
Working alongside my partner was an incredibly rewarding experience; we engaged in brainstorming sessions that allowed us to merge our unique areas of expertise. 
This collaborative effort resulted in a comprehensive plan, where we meticulously outlined each step required to produce a robust and functional program that effectively fulfills its intended purpose.

Throughout the development phase, I encountered several challenges, particularly in grasping the intricacies of how dictionaries function in Python. 
Fortunately, my teammate stepped in to offer invaluable support by sharing insights and strategies that clarified my understanding of this critical component.
The datasets we experimented with included a political speech encoded in Morse code, which added an interesting layer to our project and tested our program’s capabilities.

Looking ahead, I am excited about the potential enhancements I plan to implement in the program. One of my primary goals is to enable the software not only to convert Morse code to English but also to facilitate the reverse process—translating English text back into Morse code. This enhancement will broaden the program's functionality, making it a more versatile tool. Additionally, I see the potential for this Python program to work with various other coding systems beyond just Morse code. Users will simply need to modify the input files to fit the desired coding system, greatly expanding the utility of our solution.
