# Morse Decipher

A Python program that converts Morse-code text files into readable English and writes the decoded result to a new file.

## Purpose

The project was designed to practice file processing, dictionaries, validation, and structured problem-solving in Python. The program reads a selected Morse-code file, translates valid Morse sequences, handles invalid input, and saves the decoded text.

## Files

- `main.py` — program source code
- `algorithm.txt` — planning/algorithm notes
- `morsecode.txt` — Morse-code mapping data
- `morse1.txt`, `morse2.txt`, `morse3.txt` — sample/test inputs

## Skills practiced

- Python dictionaries
- File input/output
- String parsing
- Error checking
- Algorithm design
- Testing with multiple data sets
- Collaborative problem-solving

## Reflection

One of the most important parts of this project was learning how dictionaries can be used to map encoded values to readable characters. Working through the program also strengthened my understanding of breaking a larger problem into smaller steps, testing each part, and handling unexpected input.

A future improvement would be to support translation in both directions so the program can convert English into Morse code as well as decode Morse into English. The same basic design could also be extended to other simple encoding systems.
